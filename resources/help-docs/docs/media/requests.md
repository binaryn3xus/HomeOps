# 🎯 Requesting Movies

Looking for a movie or documentary that isn't in our library? UNSC Fleet operates an automated media request portal (**Seerr**) that enables friends and family to search, request, and track additions with a single click.

---

## 🌐 Access the Request Portal

Open the request portal from any desktop or mobile browser:

[Open Request Portal :material-cloud-search:](https://requests.unscfleet.com){ .md-button .md-button--primary target="_blank" }

---

## 🔑 How to Log In

1. Navigate to [requests.unscfleet.com](https://requests.unscfleet.com).
2. Click the **Sign In with Plex** button.
3. Authenticate with the same Plex account you use to stream our media library.
4. If you use Jellyfin without a Plex account, use the local username and password provided by an **Admin**.

---

## 🔍 How to Make a Request

1. **Browse or Search:** Use the search bar at the top or explore trending titles, upcoming theatrical releases, popular genres, and streaming collections.
2. **Review Details:** Click on any title to view high-resolution trailers, ratings, cast lists, and current availability status.
3. **Submit Request:**
   - **Movies:** Click the green **Request** button. Movie requests are automatically approved and dispatched to our high-speed acquisition pipeline!
   - **TV Shows:** Automated TV show requests are **disabled**. See the notice below.

!!! note "TV Show Requests are Disabled"
    Automated requesting for TV shows is currently disabled for regular user accounts to preserve storage capacity across our disk arrays.
    
    If there is a TV show, miniseries, or docuseries you'd like added to the library, please send a message to an **Admin** directly!

---

## 🔄 Automated Pipeline & Status Badges

Once you submit a movie request, our automated pipeline handles everything:

| Status Badge | Meaning | Next Step |
| :--- | :--- | :--- |
| :material-check-circle:{ .green } **Available** | Title is already indexed and ready to stream. | Watch now on Plex or Jellyfin! |
| :material-progress-clock:{ .amber } **Requested** | Request submitted and waiting in queue. | Pipeline will search and begin retrieval. |
| :material-download:{ .blue } **Processing / Downloading** | High-speed release is downloading. | Will complete in minutes depending on file size. |

As soon as a download finishes, the file is automatically cataloged, artwork and subtitles are fetched, and the title becomes immediately available on **Plex** and **Jellyfin**.

---

## 📢 Reporting Media Issues

Encountered an issue with a title (e.g. out-of-sync audio, incorrect subtitles, or missing scenes)?

You can report issues directly within the request portal:

1. Search for the affected title on [requests.unscfleet.com](https://requests.unscfleet.com).
2. Click **Report Issue** under the title banner.
3. Select the issue type:
   - *Video:* Corrupt video, stuttering, poor quality.
   - *Audio:* Audio out of sync, missing language track.
   - *Subtitles:* Misaligned or incorrect language.
4. Submit the report. Our automation and admins will review and replace the release with a verified copy!

## 🛠️ Troubleshooting & FAQ

??? question "How long does it take for a requested movie to become available?"
    - For released titles with abundant high-quality sources, downloads usually finish within **5 to 20 minutes**.
    - For films currently playing in movie theaters, high-definition copies will automatically download as soon as the official digital / Blu-ray release date arrives.

??? question "Why can't I request TV series or why is the TV request button disabled?"
    - Automated TV requests are disabled for user accounts because multi-season series can quickly consume hundreds of gigabytes of storage.
    - Simply send a message to **BinaryNexus** directly with the show you want to watch, and we'll gladly add it for you.

??? question "Can I get notified when my request is ready?"
    - Yes! In Seerr, click your profile avatar in the upper right → **Settings** → **Notifications** to enable notifications via email or Discord webhook.
