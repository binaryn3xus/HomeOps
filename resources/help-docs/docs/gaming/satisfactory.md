## 🎮 How to Join

1. **Ensure Tailscale is connected** and you have accepted the `unsc-gaming` machine share.
2. Launch **Satisfactory**.
3. In the Main Menu, click **Server Manager** (located on the left menu).
4. Click **Add Server** in the bottom left.
5. In the Address field, enter:
   ```text
   satisfactory.unscfleet.com:7777
   ```
   *(Alternatively, you can enter `100.64.36.88:7777`)*.
6. Click **Confirm**.
7. The server will show as online (`UNSC-Foundry`). Click **Join Game**!

> [!TIP]
> Satisfactory 1.0 uses TLS encryption for server communication. The first time you join, it may prompt you to accept the server certificate. Simply click **Accept / Confirm**.
