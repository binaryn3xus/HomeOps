## 🎮 How to Join

1. **Ensure Tailscale is connected** and running.
2. Launch **Palworld** on Steam.
3. Click **Join Multiplayer Game**.
4. At the bottom of the server browser screen, locate the direct connect input box.
5. Enter:
   ```text
   palworld.unscfleet.com:8211
   ```
   *(Or enter `100.64.36.88:8211`)*.
6. Click **Connect**!
