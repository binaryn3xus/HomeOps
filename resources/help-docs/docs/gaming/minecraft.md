## 🎮 How to Join

1. **Ensure Tailscale is connected** and you have accepted the `unsc-gaming` server share (see the [Tailscale Guide](tailscale.md)). *(If you are on local home Wi-Fi, Tailscale is not needed).*
2. Launch **Minecraft: Java Edition**.
3. In the Main Menu, click **Multiplayer** $\rightarrow$ **Add Server**.
4. Set **Server Name** to `UNSC Minecraft`.
5. In the **Server Address** field, enter:
   ```text
   minecraft.unscfleet.com
   ```
   *(Alternatively, you can enter `unsc-gaming` or `100.64.36.88`)*.
6. Click **Done**.
7. Select **UNSC Minecraft** from your server list and click **Join Server**!

---

> [!IMPORTANT] Whitelist Access Required
> The server has an active whitelist enabled to protect builds and maintain survival integrity. Before you can join for the first time, send your exact Minecraft Java username to an **Admin** so they can add you to the whitelist!

> [!TIP] Port Not Required
> Because the server runs on standard Minecraft Java port `25565`, you do not need to type `:25565` in the server address box—Minecraft connects to port 25565 automatically!
