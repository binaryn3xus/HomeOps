## 🎮 How to Join

1. Make sure **Tailscale** is running on your machine.
2. Launch your Minecraft Java Edition launcher.
3. Click **Multiplayer** $\rightarrow$ **Add Server**.
4. Set **Server Name** to `UNSC Minecraft`.
5. Set **Server Address** to:
   ```text
   minecraft.unscfleet.com:25565
   ```
6. Click **Done**, select the server, and click **Join Server**!
